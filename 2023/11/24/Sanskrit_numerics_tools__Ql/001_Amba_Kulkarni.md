Namsste,  
  
I have enclosed herewith a python programme that converts a numeral into a string, written by my student Amruta Barbadikar (in CC).  
  
Since the numbers when used as संख्येय, take the लिङ्गम् of the विशेष्य, we have used two parameters.  
If you just want the संख्या, as in counting, use the 's' option, and if you want to use it as a विशेषण, then use 'v' as the option.  
The part for "v" has errors. Please feel free to fix it.  
Below are sample input and outputs for the both.  
  
python3 numerals.py  
  
Enter a number without commas: 12345678  
  
Visheshana (enter 'v') or samkhya (enter 's') ?s  
  
12345678  
  
{'s': 'अष्टसप्ततिः-उत्तर-षट्-शत-उत्तर-पञ्च-सहस्र-उत्तर-चत्वारि-अयुत-उत्तर-त्रि-लक्ष-उत्तर-द्वि-प्रयुत-उत्तर-एक-कोटिः'}  
  
python3 numerals.py  
  
Enter a number without commas: 3  
  
Visheshana (enter 'v') or samkhya (enter 's') ?v  
  
3
