> India's cultural relations with Tibbet are so ancient and so deep
> rooted. महाव्युत्पत्ति, which is a Sanskrit-Tibetan dictionary, was
> produced in the early part of the 9th century. It is said to be the
> first bilingual dictionary in the world.  
>
>   
>
> Many other dictionaries involving Tibetan and Sanskrit have been made
> in the modern age. The [Tibetan-sanskrit dictionary by Shri J.S
> Negi](https://www.exoticindiaart.com/book/details/tibetan-sanskrit-dictionary-in-set-of-16-volumes-old-and-rare-set-uba999/)
> of Bhot-vidya-sansthan is an example.  
>
>   
>
> Now I found a project on Github for [Tibetan dictionaries in digital
> form](https://github.com/christiansteinert/tibetan-dictionary/tree/master).
> It seems to include almost all important Tibetan dictionaries. It can
> be useful for making Tibetan-Sanskrit or Sanskrit-Tibetan
> dictionaries. This project is worth seeing and adopting some ideas
> from it.
>
